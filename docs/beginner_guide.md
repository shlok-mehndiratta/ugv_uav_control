## Introduction

### What You'll Build
A robot simulation system where you can click anywhere on an overhead camera view, and a TurtleBot3 robot will autonomously navigate to that location using visual marker detection.

### System Overview
```
┌─────────────────┐
│  Gazebo Sim     │ ← Robot simulation environment
│  - TurtleBot3   │
│  - Empty World  │
│  - Overhead Cam │
└────────┬────────┘
         │
┌────────▼────────┐
│  ROS2 Topics    │ ← Communication layer
│  - /cmd_vel     │   (connects simulation to control)
│  - /image       │
│  - /odom        │
└────────┬────────┘
         │
┌────────▼────────┐
│  Control Node   │ ← Your Python code
│  - Image Proc   │   (click-to-drive logic)
│  - ArUco Detect │
│  - Navigation   │
└─────────────────┘
```

### What You'll Learn
- Setting up ROS2 workspace
- Creating custom simulation worlds in Gazebo
- Writing robot control nodes in Python
- Computer vision with ArUco markers
- Coordinate transformations and navigation algorithms

```python
from launch import LaunchDescription
from launch.actions import IncludeLaunchDescription, SetEnvironmentVariable, DeclareLaunchArgument
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from ament_index_python.packages import get_package_share_directory
import os

def generate_launch_description():
    pkg_ugv_uav = get_package_share_directory('ugv_uav_control')
    pkg_turtlebot3_gazebo = get_package_share_directory('turtlebot3_gazebo')
    
    # World file path
    world_file = os.path.join(pkg_ugv_uav, 'worlds', 'empty_with_camera.world')
    
    # Set environment variable for Gazebo resource paths
    gz_sim_resource_path = SetEnvironmentVariable(
        name='GZ_SIM_RESOURCE_PATH',
        value=[
            os.path.join(pkg_ugv_uav, 'models'),
            ':',
            os.environ.get('GZ_SIM_RESOURCE_PATH', '')
        ]
    )
    
    # Launch Gazebo with our world
    gazebo = IncludeLaunchDescription(
        PythonLaunchDescriptionSource([
            os.path.join(pkg_turtlebot3_gazebo, 'launch', 'empty_world.launch.py')
        ]),
        launch_arguments={'world': world_file}.items()
    )
    
    # Spawn TurtleBot3
    spawn_robot = Node(
        package='ros_gz_sim',
        executable='create',
        arguments=[
            '-name', 'turtlebot3_burger',
            '-topic', '/robot_description',
            '-x', '0.0',
            '-y', '0.0',
            '-z', '0.01'
        ],
        output='screen'
    )
    
    # Robot state publisher
    robot_state_publisher = Node(
        package='robot_state_publisher',
        executable='robot_state_publisher',
        output='screen',
        parameters=[{'use_sim_time': True}]
    )
    
    # Bridge for cmd_vel (ROS -> Gazebo)
    bridge_cmd_vel = Node(
        package='ros_gz_bridge',
        executable='parameter_bridge',
        arguments=['/cmd_vel@geometry_msgs/msg/TwistStamped@gz.msgs.Twist'],
        output='screen'
    )
    
    # Bridge for camera image (Gazebo -> ROS)
    bridge_camera = Node(
        package='ros_gz_bridge',
        executable='parameter_bridge',
        arguments=[
            '/overhead_camera/image@sensor_msgs/msg/Image@gz.msgs.Image',
            '/overhead_camera/camera_info@sensor_msgs/msg/CameraInfo@gz.msgs.CameraInfo'
        ],
        output='screen'
    )
    
    # Bridge for odometry (Gazebo -> ROS)
    bridge_odom = Node(
        package='ros_gz_bridge',
        executable='parameter_bridge',
        arguments=['/odom@nav_msgs/msg/Odometry@gz.msgs.Odometry'],
        output='screen'
    )
    
    # Control node
    click_to_drive_node = Node(
        package='ugv_uav_control',
        executable='click_to_drive',
        output='screen'
    )
    
    return LaunchDescription([
        gz_sim_resource_path,
        gazebo,
        spawn_robot,
        robot_state_publisher,
        bridge_cmd_vel,
        bridge_camera,
        bridge_odom,
        click_to_drive_node
    ])
```

**Understanding the Launch File:**
- **Package Paths**: Locates world files and other resources
- **Gazebo Launch**: Starts simulation with our custom world
- **Robot Spawning**: Places TurtleBot3 at origin
- **ROS-Gazebo Bridges**: Connect ROS topics to Gazebo topics
  - `/cmd_vel`: Commands from ROS to robot in Gazebo
  - `/overhead_camera/image`: Camera feed from Gazebo to ROS
  - `/odom`: Odometry data from Gazebo to ROS

**Challenge Notes:**
- **Message Type Mismatch**: Initially used `Twist`, but Gazebo expected `TwistStamped`. This caused silent failures where commands weren't received.

### Step 5: Create the Basic Control Node (Phase 1)

```bash

```

Paste this **Phase 1 version** (odometry-based):
```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from nav_msgs.msg import Odometry
from geometry_msgs.msg import TwistStamped
from cv_bridge import CvBridge
import cv2
import math

class ClickToDrive(Node):
    def __init__(self):
        super().__init__('click_to_drive')
        
        # Subscribers
        self.image_sub = self.create_subscription(
            Image, '/overhead_camera/image', self.image_callback, 10)
        self.odom_sub = self.create_subscription(
            Odometry, '/odom', self.odom_callback, 10)
        
        # Publisher
        self.cmd_pub = self.create_publisher(TwistStamped, '/cmd_vel', 10)
        
        # State variables
        self.br = CvBridge()
        self.current_image = None
        self.target_x = None
        self.target_y = None
        self.robot_x = 0.0
        self.robot_y = 0.0
        self.robot_theta = 0.0
        
        # Camera parameters
        self.camera_height = 10.0
        self.fov = 1.047  # 60 degrees in radians
        self.image_width = None
        self.image_height = None
        self.scale = None  # meters per pixel
        
        # Control loop timer (20 Hz)
        self.timer = self.create_timer(0.05, self.control_loop)
        
        self.get_logger().info('Click to Drive Node Started (Odometry Mode)')

    def image_callback(self, msg):
        try:
            self.current_image = self.br.imgmsg_to_cv2(msg, "bgr8")
            
            # Calibrate on first image
            if self.image_width is None:
                self.image_height, self.image_width = self.current_image.shape[:2]
                # Calculate scale: how many meters per pixel
                world_width = 2 * self.camera_height * math.tan(self.fov / 2)
                self.scale = world_width / self.image_width
                self.get_logger().info(f'Camera calibrated. Scale: {self.scale:.5f} m/px')
            
            # Draw robot position (blue dot)
            if self.scale is not None:
                px = int(self.image_width / 2 - self.robot_y / self.scale)
                py = int(self.image_height / 2 - self.robot_x / self.scale)
                cv2.circle(self.current_image, (px, py), 5, (255, 0, 0), -1)
            
            # Draw target (red dot)
            if self.target_x is not None and self.scale is not None:
                px = int(self.image_width / 2 - self.target_y / self.scale)
                py = int(self.image_height / 2 - self.target_x / self.scale)
                cv2.circle(self.current_image, (px, py), 5, (0, 0, 255), -1)
            
            # Resize for display (50% size)
            display_image = cv2.resize(self.current_image, (960, 540))
            cv2.imshow("Overhead Camera", display_image)
            cv2.setMouseCallback("Overhead Camera", self.mouse_callback)
            cv2.waitKey(1)
        except Exception as e:
            self.get_logger().error(f'Image processing error: {e}')

    def mouse_callback(self, event, x, y, flags, param):
        if event == cv2.EVENT_LBUTTONDOWN:
            if self.scale is None:
                return
            # Scale click back to original image size
            orig_x = x * 2
            orig_y = y * 2
            # Convert pixel to world coordinates
            self.target_x = (self.image_height / 2 - orig_y) * self.scale
            self.target_y = (self.image_width / 2 - orig_x) * self.scale
            self.get_logger().info(f'New target: ({self.target_x:.3f}, {self.target_y:.3f})')

    def odom_callback(self, msg):
        # Extract position
        self.robot_x = msg.pose.pose.position.x
        self.robot_y = msg.pose.pose.position.y
        
        # Extract orientation (convert quaternion to yaw)
        q = msg.pose.pose.orientation
        siny_cosp = 2 * (q.w * q.z + q.x * q.y)
        cosy_cosp = 1 - 2 * (q.y * q.y + q.z * q.z)
        self.robot_theta = math.atan2(siny_cosp, cosy_cosp)

    def control_loop(self):
        if self.target_x is None:
            return
        
        # Calculate distance to target
        dx = self.target_x - self.robot_x
        dy = self.target_y - self.robot_y
        distance = math.sqrt(dx*dx + dy*dy)
        
        cmd = TwistStamped()
        cmd.header.stamp = self.get_clock().now().to_msg()
        cmd.header.frame_id = 'base_link'
        
        if distance > 0.05:  # 5cm tolerance
            # Calculate angle to target
            angle_to_target = math.atan2(dy, dx)
            angle_diff = angle_to_target - self.robot_theta
            
            # Normalize angle difference to [-pi, pi]
            while angle_diff > math.pi:
                angle_diff -= 2 * math.pi
            while angle_diff < -math.pi:
                angle_diff += 2 * math.pi
            
            # Proportional control
            speed = 0.5 * distance
            cmd.twist.linear.x = min(max(speed, 0.05), 0.25)  # Clamp to [0.05, 0.25]
            cmd.twist.angular.z = 1.5 * angle_diff
            
            # Stop forward motion if angle is too large
            if abs(angle_diff) > 0.5:
                cmd.twist.linear.x = 0.0
        else:
            # Stop at target
            cmd.twist.linear.x = 0.0
            cmd.twist.angular.z = 0.0
        
        self.cmd_pub.publish(cmd)

def main(args=None):
    rclpy.init(args=args)
    node = ClickToDrive()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()
        cv2.destroyAllWindows()

if __name__ == '__main__':
    main()
```

Make it executable:
```bash
chmod +x click_to_drive.py
```

**Understanding the Control Logic:**

1. **Coordinate System**:
   ```
   Image Coordinates          World Coordinates
   (0,0) ┌─────────┐          ┌─────────┐ +Y
         │         │          │         │
         │    ●    │          │    ●    │
         │  robot  │    <==>  │  robot  │
         └─────────┘          └─────────┘ +X
              (W,H)
   ```
   - Image: Origin at top-left, Y increases downward
   - World: Origin at center, standard XY plane

2. **Scaling Math**:
   ```
   FOV (60°) determines visible width at height H
   
   Visible Width = 2 * H * tan(FOV/2)
   Scale = Visible Width / Image Width (pixels)
   
   Example: H=10m, FOV=60°, Width=1920px
   Visible Width = 2 * 10 * tan(30°) ≈ 11.55m
   Scale = 11.55 / 1920 ≈ 0.006 m/px
   ```

3. **Navigation Algorithm**:
   - Calculate distance and angle to target
   - Turn towards target if angle is large
   - Move forward once aligned
   - Stop when within 5cm tolerance

**Challenge Notes:**
- **Coordinate Conversion**: Getting the pixel-to-world transformation correct required careful consideration of image vs world coordinate systems.
- **Control Instability**: Initial proportional gains caused oscillation. Tuned to `0.5` for linear and `1.5` for angular.

## Phase 2: ArUco Marker-Based Visual Localization

In Phase 2, we replace odometry with visual localization using ArUco markers, providing more realistic positioning without relying on simulation ground truth.

### Why ArUco Markers?

**Problem with Odometry:**
- Relies on simulation's perfect knowledge of robot position
- Not realistic for real-world deployment
- Accumulates error over time (wheel slip, uneven terrain)

**ArUco Solution:**
- Visual fiducial markers detectable by OpenCV
- Provides absolute position measurement
- Works with standard cameras
- Used in robotics, AR/VR, and calibration

### Step 8: Generate ArUco Marker

Create marker generation script:
```bash
cd ~/turtlebot3_ws/src/ugv_uav_control
nano generate_marker.py
```

Paste:
```python
#!/usr/bin/env python3
import cv2
import cv2.aruco as aruco
import numpy as np
import sys

print(f"OpenCV Version: {cv2.__version__}")

# Create ArUco dictionary (4x4, 50 markers)
aruco_dict = aruco.getPredefinedDictionary(aruco.DICT_4X4_50)

# Generate marker ID 0, size 200x200 pixels
marker_size = 200

try:
    # Try newer OpenCV API
    marker_image = aruco.generateImageMarker(aruco_dict, 0, marker_size)
except AttributeError:
    # Fallback for older OpenCV versions
    try:
        marker_image = aruco.drawMarker(aruco_dict, 0, marker_size)
    except AttributeError:
        print("Error: ArUco marker generation not supported")
        sys.exit(1)

# Add white padding (critical for detection!)
pad_width = 50
marker_image = cv2.copyMakeBorder(
    marker_image, pad_width, pad_width, pad_width, pad_width,
    cv2.BORDER_CONSTANT, value=255
)

# Save to models directory
import os
os.makedirs('models/turtlebot3_burger_aruco/materials/textures', exist_ok=True)
output_path = 'models/turtlebot3_burger_aruco/materials/textures/aruco_marker_0.png'
cv2.imwrite(output_path, marker_image)
print(f"Marker saved to {output_path}")
```

Run it:
```bash
python3 generate_marker.py
```

**Understanding ArUco Markers:**
```
┌─────────────────┐
│  White Border   │  ← Essential for detection
│  ┌───────────┐  │
│  │ ■ □ □ ■ │  │  ← 4x4 binary pattern
│  │ □ ■ ■ □ │  │     (unique ID encoding)
│  │ ■ □ ■ □ │  │
│  │ □ ■ □ ■ │  │
│  └───────────┘  │
└─────────────────┘
```

**Challenge Notes:**
- **White Border**: Initially generated markers without padding. Detection failed completely. Adding 50px white border was essential.
- **OpenCV Version**: Different OpenCV versions use different API functions. Added fallback for compatibility.

Replace entire file with:
```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from geometry_msgs.msg import TwistStamped
from cv_bridge import CvBridge
import cv2
import cv2.aruco as aruco
import math
import numpy as np

class ClickToDrive(Node):
    def __init__(self):
        super().__init__('click_to_drive')
        
        self.subscription = self.create_subscription(
            Image,
            '/overhead_camera/image',
            self.image_callback,
            10)
            
        self.publisher_ = self.create_publisher(TwistStamped, '/cmd_vel', 10)
        
        self.br = CvBridge()
        self.current_image = None
        self.target_x = None
        self.target_y = None
        
        self.robot_x = None
        self.robot_y = None
        self.robot_theta = None
        
        # Camera parameters
        self.camera_height = 10.0
        self.fov = 1.047 # 60 degrees
        self.image_width = None
        self.image_height = None
        self.scale = None
        
        # ArUco Dictionary
        self.aruco_dict = aruco.getPredefinedDictionary(aruco.DICT_4X4_50)
        try:
            self.aruco_params = aruco.DetectorParameters_create()
        except AttributeError:
            self.aruco_params = aruco.DetectorParameters()
        
        self.timer = self.create_timer(0.05, self.control_loop)
        
        self.get_logger().info('Click to Drive Node Started (ArUco Mode).')

    def image_callback(self, msg):
        try:
            self.current_image = self.br.imgmsg_to_cv2(msg, "bgr8")
            
            if self.image_width is None:
                self.image_height, self.image_width = self.current_image.shape[:2]
                # Calculate scale (meters per pixel)
                world_width = 2 * self.camera_height * math.tan(self.fov / 2)
                self.scale = world_width / self.image_width
                self.get_logger().info(f'Camera Calibrated. Scale: {self.scale:.5f} m/px')
            
            # Detect ArUco markers
            gray = cv2.cvtColor(self.current_image, cv2.COLOR_BGR2GRAY)
            corners, ids, rejected = aruco.detectMarkers(gray, self.aruco_dict, parameters=self.aruco_params)
            
            if ids is not None and len(ids) > 0:
                self.get_logger().info(f'ArUco Marker Detected: {ids}', throttle_duration_sec=2.0)
                for i in range(len(ids)):
                    if ids[i][0] == 0: # Robot Marker ID
                        # Get center
                        c = corners[i][0]
                        cx = int(np.mean(c[:, 0]))
                        cy = int(np.mean(c[:, 1]))
                        
                        # Convert to world coordinates
                        self.robot_x = (self.image_height / 2 - cy) * self.scale
                        self.robot_y = (self.image_width / 2 - cx) * self.scale
                        
                        # Calculate orientation from marker corners
                        # Corners are ordered: top-left, top-right, bottom-right, bottom-left
                        # Front is average of top two corners
                        front_x = (c[0][0] + c[1][0]) / 2
                        front_y = (c[0][1] + c[1][1]) / 2
                        
                        wx_front = (self.image_height / 2 - front_y) * self.scale
                        wy_front = (self.image_width / 2 - front_x) * self.scale
                        
                        self.robot_theta = math.atan2(wy_front - self.robot_y, wx_front - self.robot_x)
                        
                        # Draw marker outline
                        cv2.polylines(self.current_image, [c.astype(np.int32)], True, (0, 255, 0), 2)
                        cv2.circle(self.current_image, (cx, cy), 5, (255, 0, 0), -1)
            
            # Draw target
            if self.target_x is not None:
                px = int(self.image_width / 2 - self.target_y / self.scale)
                py = int(self.image_height / 2 - self.target_x / self.scale)
                cv2.circle(self.current_image, (px, py), 5, (0, 0, 255), -1)

            # Resize for display (50% size)
            display_image = cv2.resize(self.current_image, (960, 540))
            cv2.imshow("Overhead Camera", display_image)
            cv2.setMouseCallback("Overhead Camera", self.mouse_callback)
            cv2.waitKey(1)
        except Exception as e:
            self.get_logger().error(f'Error processing image: {e}')

    def mouse_callback(self, event, x, y, flags, param):
        if event == cv2.EVENT_LBUTTONDOWN:
            if self.scale is None: return
            # Scale click coordinates back to original image size
            orig_x = x * 2
            orig_y = y * 2
            # Convert pixel to world
            self.target_x = (self.image_height / 2 - orig_y) * self.scale
            self.target_y = (self.image_width / 2 - orig_x) * self.scale
            self.get_logger().info(f'New Target: ({self.target_x:.3f}, {self.target_y:.3f})')

    def control_loop(self):
        if self.target_x is None: return
        if self.robot_x is None:
            self.get_logger().warn('Waiting for ArUco marker detection...', throttle_duration_sec=2.0)
            return
            
        dx = self.target_x - self.robot_x
        dy = self.target_y - self.robot_y
        dist = math.sqrt(dx*dx + dy*dy)
        
        cmd = TwistStamped()
        cmd.header.stamp = self.get_clock().now().to_msg()
        cmd.header.frame_id = 'base_link'
        
        if dist > 0.05: # 5cm tolerance
            angle_to_target = math.atan2(dy, dx)
            angle_diff = angle_to_target - self.robot_theta
            
            while angle_diff > math.pi: angle_diff -= 2*math.pi
            while angle_diff < -math.pi: angle_diff += 2*math.pi
            
            speed = 0.5 * dist
            cmd.twist.linear.x = min(max(speed, 0.05), 0.25)
            cmd.twist.angular.z = 1.5 * angle_diff
            
            if abs(angle_diff) > 0.5:
                cmd.twist.linear.x = 0.0
        else:
            cmd.twist.linear.x = 0.0
            cmd.twist.angular.z = 0.0
            
        self.publisher_.publish(cmd)

def main(args=None):
    rclpy.init(args=args)
    node = ClickToDrive()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()
        cv2.destroyAllWindows()

if __name__ == '__main__':
    main()
```

**Key Differences from Phase 1:**
- Removed odometry subscriber
- Added ArUco detection
- Calculates position and orientation from marker corners
- Only moves when marker is detected

## Common Issues and Solutions

### Issue 1: ArUco Marker Not Detected

**Symptoms:**
- No "ArUco Marker Detected" messages
- No green box in camera view
- Robot doesn't move (waits for detection)

**Diagnosis:**
```bash
# Save current camera frame
ros2 run image_view image_saver --ros-args -r image:=/overhead_camera/image

# Test marker detection offline
python3 << EOF
import cv2
import cv2.aruco as aruco

img = cv2.imread('left0000.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
aruco_dict = aruco.getPredefinedDictionary(aruco.DICT_4X4_50)
params = aruco.DetectorParameters()
corners, ids, rejected = aruco.detectMarkers(gray, aruco_dict, parameters=params)
print(f"Detected: {ids}")
print(f"Rejected: {len(rejected)}")
EOF
```

**Solutions:**
1. **Marker too small**: Increase size in `model.sdf` (try 0.7 x 0.7 m)
2. **Camera resolution low**: Already at 1920x1080 in our setup
3. **Missing white border**: Regenerate marker with padding
4. **Lighting issues**: Add more lights to Gazebo world
5. **PBR material not loading**: Verify texture file path is absolute

### Issue 2: Robot Moves to Wrong Location

**Symptoms:**
- Click at location A, robot goes to location B
- Offset is consistent

**Solutions:**
1. **Coordinate system mismatch**: Verify transformation in `mouse_callback`
2. **Scale calculation wrong**: Check FOV matches camera settings
3. **Display resize issue**: Ensure mouse coordinates are scaled back (x*2, y*2)

### Issue 3: Robot Oscillates at Target

**Symptoms:**
- Reaches target but wobbles back and forth
- Never fully stops

**Solutions:**
1. **Tolerance too tight**: Increase from 0.05 to 0.10 in control loop
2. **Gains too high**: Reduce proportional gain from 0.5 to 0.3
3. **Control loop too fast**: Increase timer period from 0.05 to 0.1

### Issue 4: Simulation Crashes

**Symptoms:**
- Gazebo closes unexpectedly
- Segmentation fault errors

**Solutions:**
1. **GPU issues**: Set `GZ_SIM_RESOURCE_PATH` and restart
2. **Too many bridges**: Combine bridge arguments into fewer nodes
3. **Memory leak in OpenCV**: Add `cv2.destroyAllWindows()` in cleanup

### Issue 5: Camera Window Too Large

**Already solved in our code:**
```python
display_image = cv2.resize(self.current_image, (960, 540))
cv2.imshow("Overhead Camera", display_image)
```

If you need different size:
