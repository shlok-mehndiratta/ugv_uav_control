# Documentation

This directory contains comprehensive documentation for the Cooperative Aerial-Ground Guidance System project.

## 📄 Available Documents

### [project_log.html](project_log.html)
**Technical Project Log** - Detailed development history with:
- Mathematical foundations and derivations
- Implementation details with code snippets
- Challenges encountered and solutions
- Performance metrics and analysis
- Media placeholders for images/videos

**Best for:** Technical review, understanding implementation details, academic presentations

### [beginner_guide.md](beginner_guide.md)
**Beginner's Tutorial** - Step-by-step guide for reproducing the project:
- Complete installation instructions
- Phase-by-phase development walkthrough
- Common issues and troubleshooting
- Testing procedures

**Best for:** New team members, reproducing the project from scratch

## 📝 Adding Updates

### To update project_log.html:

1. Open the file in a text editor
2. Scroll to the "Add New Progress" section at the bottom
3. Copy the provided template
4. Paste it into the appropriate section (Foundation, Implementation, Vision, etc.)
5. Fill in your milestone details:
   - Objective
   - Implementation (with code)
   - Mathematical foundations
   - Challenges and solutions
   - Key learnings

### To add media (images/videos):

Replace media placeholders with actual content:

```html
<!-- Replace this: -->
<div class="media-placeholder">
    <h4>📹 Media: Description</h4>
    <p>What to show...</p>
</div>

<!-- With this: -->
<img src="path/to/image.png" alt="Description" style="max-width:100%">
<!-- or -->
<video controls style="max-width:100%">
    <source src="path/to/video.mp4">
</video>
```

## 🎯 Documentation Guidelines

When adding new progress:

1. **Focus on achievements** - What was accomplished, not time spent
2. **Include math** - Explain underlying equations and derivations
3. **Add code snippets** - Show key implementations
4. **Document challenges** - Include root cause analysis
5. **Explain decisions** - Why you chose a particular approach
