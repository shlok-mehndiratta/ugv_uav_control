# docs/

- **`PROJECT_HISTORY.md`** — the research history behind the paper: what was tried, what failed, and
  why the framing changed. The best starting point for anyone continuing the work.
- **`planning/`** — the initial planning notes (paper plan, outline, literature survey, simulation
  plan, reframe plan). Kept **for reference only**; they capture early planning, not the final record.
  The authoritative sources are the paper (`paper/ACODS.tex`) and `PROJECT_HISTORY.md`.
- **`drafts/`** — superseded per-section drafts (related work, system models, theory) that were later
  merged into the final paper. Kept **for reference only**.
